Courier Ledger

دفتر حساب پیک موتوری با React، Vite و Supabase.

امکانات

- ثبت، جست‌وجو، ویرایش و حذف سفارش‌ها
- فیلتر سفارش‌ها بر اساس تاریخ
- گزارش کرایه، فاکتور و روش‌های پرداخت ثبت‌شده
- تخمین کمیسیون بر اساس نرخ ۲۰ درصد
- ثبت هزینه‌های موتور، کیلومتر و یادآور سرویس
- ثبت تسویه‌های واقعی
- خروجی CSV برای سفارش‌ها و هزینه‌های موتور
- رابط کاربری فارسی و واکنش‌گرا

راه‌اندازی

npm install
npm run dev

متغیرهای محیطی

متغیرهای زیر باید در فایل ".env.local" یا تنظیمات محیطی میزبان تعریف شوند:

VITE_SUPABASE_URL=https://YOUR_PROJECT.supabase.co
VITE_SUPABASE_ANON_KEY=YOUR_SUPABASE_PUBLISHABLE_OR_ANON_KEY

کلید واقعی را در مخزن عمومی قرار ندهید.

پایگاه داده

پیش از استفاده از بخش هزینه‌های موتور، فایل
"supabase/migration_motorcycle_expenses.sql"
را در SQL Editor پروژهٔ Supabase اجرا کنید.

ساخت نسخهٔ نهایی

npm run build

خروجی ساخت در پوشهٔ "dist" ایجاد می‌شود.

نکات حسابداری

کمیسیون نمایش‌داده‌شده در گزارش‌ها تخمینی است.
فاکتور مغازه درآمد پیک محسوب نمی‌شود.
مبلغ پوز دفتر ممکن است شامل فاکتور و کرایه باشد؛
بنابراین بدون ثبت جزئیات واقعی نمی‌توان آن را درآمد خالص دانست.
